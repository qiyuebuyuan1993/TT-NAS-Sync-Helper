# NAS 同步助手

TauriTavern 的第三方扩展：电脑一键增量上传/下载、启动下载、退出交接提醒；手机仅提供原生同步面板入口。

## 安装

在 TT 的「扩展 → 安装扩展」输入：

```
https://github.com/qiyuebuyuan1993/TT-NAS-Sync-Helper
```

安装后刷新 TT，在扩展设置里找到 **NAS 同步助手**。仅适用于 TauriTavern，不适用于服务器版 SillyTavern。

v0.2.0 新增两个快捷入口：输入框旁的 **魔法棒 → NAS 同步**，以及自动添加的 **NAS 同步** 快速回复按钮（独立集合 `TT-NAS-Sync-Helper`）。两者都只打开原生同步页，不会直接传输数据。可手动执行 `/tt-nas-sync`。

若快速回复未显示，先确认快速回复扩展及按钮显示已开启，再到本插件设置点击「添加快速回复按钮」。重复添加不会重复创建按钮或覆盖其他集合。

退出提醒的「返回 TT，打开同步」会先取消退出，再自动打开同步页；按 Esc 仅取消退出。

## 第一次设置

1. 每台设备先在 TT 原生同步面板配对自己的 NAS。外网使用私有组网时，请先连接相应客户端。
2. 原生面板选择需要同步的数据。千千结的 TT 扩展存储适配需要 **扩展存储 `extensions.store`**（部分界面显示「扩展商店」）。插件缺少该选项时会停止，不会偷偷增加同步范围。
3. 电脑在插件下拉框选择已经配对的 NAS。确认这台设备的现有内容可以由 NAS 同名文件替换后，勾选「下次启动自动从所选 NAS 下载」。每台电脑单独开启。
4. 手机没有自动上传、自动下载、退出钩子。点击「打开同步面板」，按原生流程操作。

目标选择按设备分别保存。外网电脑选私有组网地址，家里的电脑选 NAS 局域网地址；插件不会自动探测网络或切换地址。同一设备切换连接方式时，请先在原生面板确认其已配对地址可达。

## 日常交接

- 当前电脑聊完，等待生成和记忆处理结束，点击 **上传到 NAS**，等原生成功提示。
- 关闭 TT 时会提醒最近上传时间。确认上传后没有再修改，选 **确认上传后未再修改，退出**。
- 换电脑：启动 TT 后自动下载；原生提示完成后确认刷新，再继续聊天。
- 若选择直接退出、取消退出、应用崩溃、强制关闭，插件保留「未交接」标记。下次自动下载暂停，请检查本地内容后手动上传或下载。
- 手机换设备前在原生面板手动上传；下一台设备下载后再开始聊天。不要同时在两台设备修改同一聊天。

## 行为与限制

- 固定 **Incremental**。不删除目标独有文件，但同名文件仍受原生冲突策略影响；不合并聊天记录。
- 同步范围、冲突策略、认证、证书校验、传输、应用数据和结果提示均由 TT 原生实现提供。
- 目标选择、自动下载开关、交接标记、上传时间仅存在当前 WebView 的 `localStorage`，不写入同步的扩展设置。刷新保护使用 `sessionStorage`。
- 只记录本插件上传成功的时间。原生面板或其他自动任务的上传不会被误记为本插件已完成交接。
- 无法可靠判断所有扩展是否在后台修改了数据，因此 **每次正常退出都提醒，由用户确认交接**，不宣称精确识别所有未上传变更。
- 退出提醒依赖 TT 正常关闭事件；任务管理器结束进程、断电、系统强制关机不保证提醒。关闭到托盘的行为由 TT 决定。
- 不会开启公网路由、绕过证书认证、自动配对或存储账号密码。仓库不含私人 NAS 地址、配对信息或聊天。
- 当前接口按 **TauriTavern v2.4.0** 核对；使用 TT 内部模块，升级 TT 后若接口变化会显示错误，应使用原生面板。插件不是官方产品。

## 停用

在 TT 扩展管理中停用此扩展并刷新。原生 TT-Sync 配对和数据不受影响。
如果不再使用，请同时在快速回复设置中停用或移除 `TT-NAS-Sync-Helper` 集合，避免调用已停用的命令。
